# Git Workflow Instructions
- **Feature Branch Rule**: BEFORE making any file edits or running implementation steps for a new feature, bugfix, or task:
  1. Check current git status and branch (`git status`).
  2. If on `main`, `master`, or `dev`, automatically create and switch to a new feature branch using `git checkout -b feature/<descriptive-name>`.
  3. Do NOT make changes directly on main branches.
